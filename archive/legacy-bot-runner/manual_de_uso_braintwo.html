Manual de Uso

Plataforma Fleet

¡Bienvenido al manual central de Fleet! Fleet es una herramienta versátil diseñada para alojar y ejecutar todo tipo de automatizaciones (bots). Aquí aprenderás cómo administrarlos independientemente de lo que haga cada uno.

1. La Flota de Automatizaciones

Fleet actúa como un "centro de comando" universal. Al ser tan flexible, los bots que instales pueden comportarse de maneras muy distintas dependiendo de para qué fueron programados:

  • 📂 Bots con Archivos Locales Ejemplo: Toman PDFs de una carpeta, los leen y devuelven un Excel. Trabajan 100% de fondo sin que los veas actuar.
  • 🌐 Bots de Navegación Web Ejemplo: Abren una ventana de Chrome "invisible" para iniciar sesión en una página del estado o extraer datos de una web (Scraping).
  • 🤖 Bots Interactivos o con UI Ejemplo: Al ejecutarlos, podrían abrir su propia ventana para pedirte datos (como contraseñas, fechas o selecciones).
  • ⚙️ Bots de Sistema Ejemplo: Tareas planificadas como organizar carpetas, enviar emails masivos o sincronizar bases de datos cada cierto tiempo.

2. Gestión de tu Panel (Dashboard)

Instalar un Bot mediante ZIP

Fleet permite instalar cualquier bot compatible. Sin importar lo que haga, el método siempre es el mismo:

  • Localiza la barra "Instalar Bot desde ZIP" en la pantalla principal.
  • Escribe o pega la ruta completa de tu archivo (por ejemplo: C:\Usuarios\TuNombre\Downloads\RobotNuevasVentas.zip).
  • Haz clic en el botón "Instalar". Fleet lo descomprimirá y lo pondrá en tu listado.

Ejecutar (Correr) y Monitorear

Para despertar a un bot y que inicie su rutina:

  • En su tarjeta, haz clic en el botón de Play azul o verde ( ▶ ).
  • Presta atención al panel de Actividad. Este panel es crucial, ya que si es un bot web, podría avisarte "Navegando a la página...". Si es un bot de archivos, te dirá "Procesando 3 de 10...".
  • Para algunos bots, no necesitarás hacer nada más. Otros, en cambio, pueden pedirte de manera adicional abrir un navegador u otorgar un permiso en pantalla.

Desinstalar (Eliminar) un Bot

Cuando un proceso ya no sea necesario en la empresa:

  • Ubica el botón de la cruz ( ✖ ) en la esquina de su tarjeta y haz clic en él.
  • Atención: Esta acción borrará el bot de Fleet permanentemente. Si es un bot de archivos, es buena práctica hacer un respaldo de su carpeta `output` antes de borrarlo.

3. Explorar los Archivos (Carpeta 📂)

Importante: Esta sección aplica solamente a los bots que requieren leer o escribir documentos en tu computadora. Si tu bot se conecta directamente a SAP u otras web mediante bases de datos, tal vez no uses estas carpetas nunca.

Si haces clic en el ícono de carpeta ( 📂 ), se abrirá el directorio del bot. Para los procesos basados en tareas de oficina (Office/PDFs), encontrarás esta estructura típica:

input

Es la "bandeja de entrada". Aquí se colocan los Excels, imágenes o PDFs base. Si el bot exige parámetros de entrada (como listas de clientes), aquí es donde los leerá, así que debes llenarla antes de presionar ( ▶ ).

output

Es la "bandeja de salida". Una vez que el bot te notifique en el panel de Actividad que "Finalizó con éxito", aquí encontrarás sus reportes, archivos renombrados o Excels listos.

Para CUALQUIER tipo de bot (sea de archivos, web o de sistema), es común que encuentres estas dos carpetas universales:

logs

El diario de tu bot. Archivos de texto donde el bot registra cada paso y cada "error" (ej. "La web se cayó en el paso 4" o "No encuentro el Excel"). Muy útil para enviar a soporte si algo falla.

support / docs

Cada automatización es un mundo y tiene sus propias reglas. Aquí vas a encontrar los Manuales de Uso Específicos escritos por el desarrollador para enseñarte a operar particularmente ESE bot.
